Vehicle Insurance Claim Fraud Detection
📌 Overview

This project focuses on analyzing vehicle insurance claims to identify fraudulent and non-fraudulent patterns using Python and Power BI. The analysis helps uncover fraud trends based on customer demographics, policy details, and vehicle-related factors through interactive dashboards and data visualization.

🎯 Project Objectives
Identify fraudulent vs non-fraudulent insurance claims
Analyze fraud trends across customer demographics
Detect patterns based on vehicle category, price, and age
Build interactive dashboards for fraud analysis and reporting

🛠️ Tech Stack
Python – Data cleaning and preprocessing
Pandas & NumPy – Data analysis
Power BI – Interactive dashboard and visualization

🔍 Key Analysis Performed
Fraud Analysis
Fraudulent vs non-fraudulent claims
Fraud percentage and claim distribution
High-risk customer identification
Customer Insights
Fraud trends by:
Age group
Gender
Marital status
Policy type
Vehicle Insights
Fraud patterns based on:
Vehicle category
Vehicle price
Vehicle age

📈 Dashboard Features
KPI cards for fraud metrics
Stacked bar charts and donut charts
Interactive filters and slicers
Fraud trend visualizations
Customer and vehicle-based analysis

⚙️ Workflow
Collected and cleaned insurance claim data using Python
Processed and analyzed datasets for fraud patterns
Built Power BI dashboards for interactive reporting
Generated insights to support fraud detection analysis

🚀 Key Insights
Certain customer demographics showed higher fraud occurrence
Specific vehicle categories had increased fraudulent claims
Fraud patterns varied across policy and claim types
Interactive dashboards improved fraud trend analysis

📌 Conclusion
This project demonstrates how data analytics and visualization can be used to detect suspicious insurance claim patterns and support fraud prevention using Python and Power BI.
